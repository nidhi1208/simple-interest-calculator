# Simple Interest Calculator

A simple Bash-based calculator that computes simple interest based on the principal amount, rate of interest, and time period provided by the user.

## Formula

Simple Interest (SI) is calculated using the formula:

SI = (P × R × T) / 100

Where:

- P = Principal amount
- R = Rate of interest
- T = Time period

## Features

- Accepts principal amount from the user
- Accepts rate of interest from the user
- Accepts time period from the user
- Calculates simple interest
- Displays the calculated simple interest
